# wAIter 🎙️🍽️
### AI-Powered Restaurant Voice Assistant

**wAIter** is a voice-first AI product designed to fundamentally change how people interact with restaurant menus. 

Today’s digital menus, even tablet-based ones, still rely on scanning, reading, filtering, and guessing. This creates friction for customers, increases reliance on waitstaff, and excludes entire audiences such as children, elderly users, tourists, and anyone overwhelmed by large menus.

**wAIter** replaces this experience with something significantly more intuitive. Customers speak naturally to describe cravings, mood, preferences, or restrictions, and receive clear, personalized dish recommendations in real time.

---

## Key Features

* **Voice-to-Recommendation Pipeline:** A production-level full-stack system that converts natural voice input into personalized menu recommendations using GenAI.
* **Seamless Multilingual Support:** Enables customers to speak in their native language while the system intelligently maps requests to the restaurant’s original menu database.
* **Semantic Understanding:** Real-time analysis of cravings, mood, and dietary restrictions.
* **Dynamic Menu Integration:** Real menu data pulled dynamically from the restaurant's SQL database.

---

## Technical Stack

* **Frontend:** React
* **Backend:** Node.js
* **Database:** MySQL
* **AI Engine:** Gemini API (GenAI-based semantic understanding)
* **DevOps:** Docker & Docker-Compose
* **CI/CD:** Jenkins
* **Testing:** Jest (Unit & Integration testing)

---

## System Architecture & Implementation

* **Full-Stack Integration:** Built a robust system: `Voice Input >> GenAI Semantic Understanding >> Structured, Reliable Recommendations`.
* **Modular Backend:** Designed to handle audio files, database integration, and structured JSON AI responses efficiently.
* **Containerization:** The entire system is containerized with **Docker-Compose** for consistent and reproducible deployment across different environments.
* **Reliability:** Implemented comprehensive unit and integration testing with **Jest** to ensure system stability.
* **Automation:** Full **CI/CD pipeline** managed by **Jenkins** for seamless development and deployment.
